# 💸 分帳小幫手 (FairSplit)

> 隨時可用・極簡黑白高對比・免註冊・支援多人手機掃碼即時協同・PWA 離線支援

🔗 **線上正式網址**：[https://ivanhuang2031.github.io/fairsplit/](https://ivanhuang2031.github.io/fairsplit/)  
📦 **GitHub 倉庫**：[https://github.com/IvanHuang2031/fairsplit](https://github.com/IvanHuang2031/fairsplit)

「分帳小幫手」專為朋友聚會、情侶出遊、團體旅行設計，提供最極簡順暢的分帳體驗。

---

## ✨ 核心特色功能

### 1. 👥 成員人數自由設定
- 隨時新增、修改、刪除分帳成員。
- 支援快速帶入預設範例名單。

### 2. 💳 全功能支出記錄
- **誰付款**：支援單人付款代墊，亦支援「多人共同代墊」（各出不同金額，系統即時驗證總合）。
- **怎麼分**：
  1. **全員平分**：自動平攤給全部成員。
  2. **特定人分**：勾選特定成員平分（例如：有人沒喝酒不平攤酒錢）。
  3. **依份數/權重**：依照比例分攤（例如：大人 2 份、小孩 1 份）。
  4. **自訂金額**：各自分攤精確金額（例如：各點各的餐點）。
- 內建分類標籤（餐飲、交通、住宿、門票、購物、其他）與日期備註。

### 3. 🔄 貪心演算法最小轉帳結算
- 自動計算每位成員的「已付金額」、「應攤金額」與「淨收支差額」。
- 透過**貪婪最小現金流演算法（Minimum Cash Flow）**，將複雜的環狀欠款簡化為**最少轉帳次數**（例如：A 欠 B、B 欠 C，自動化為 A 付給 C）。
- 支援整數四捨五入（自動平分除不盡的餘數零頭）或精確小數點切換。
- 支援幣別切換（TWD, JPY, USD, EUR, KRW, HKD）。

### 4. ⚡ 免設定 WebRTC P2P 多人手機即時協同
- 點擊「開啟同步」立即產生 6 位數房間碼與 **QR Code**。
- 朋友打開手機相機一掃立刻進房，**每個人在自己手機上記帳，所有人螢幕秒級同步**！
- 免註冊、免伺服器費用、點對點端到端傳輸，極度保障隱私。

### 5. 💬 一鍵複製 LINE 友善純文字
- 一鍵複製排版好的結算報告（包含活動名稱、總支出、人均消費、個人收支明細、最佳還款路線與還原網址），直接發送至 LINE、Messenger 或群組聊天室。

### 6. 📱 PWA 離線支援與深淺色主題
- 採用極簡黑白深淺主題（Dark/Light Mode），高對比、數字清晰。
- 支援 PWA，可直接「加到主畫面」當作原生 App 離線使用。
- 資料隨打隨存於手機 LocalStorage，重整或意外關閉不遺失。

## 🚀 本地啟動與開發

```bash
# 安裝依賴
npm.cmd install

# 啟動本地開發伺服器
npm.cmd run dev

# 執行自動化測試
npm.cmd test

# 打包生產版本
npm.cmd run build
```

啟動後瀏覽器打開 `http://localhost:5173` 即可立即使用！

## 🌐 部署方式

本專案為純前端靜態應用，可免費部署到任何靜態網站平台：
- **Vercel**：匯入 GitHub 倉庫即可一鍵發布。
- **GitHub Pages**：直接將 `dist/` 資料夾發布至 `gh-pages` 分支。
- **Netlify / Cloudflare Pages**：選擇 build 指令為 `npm run build`，目錄為 `dist`。
